# MyEverything — متصفح مشترك حي

ديسكتوب (ويندوز + ماك) **و** موقع ويب، يخلوا شخصين يشوفوا نفس المتصفح لحظياً
ويلعبوا **AirConsole** مع بعض عن بعد. المضيف يفتح AirConsole على جهازه، والضيف
يشوف نفس الشاشة ويتحكم فيها، وكل واحد يلعب بموبايله كدراع.

> ملحوظة صريحة عن التأخير: صفر تأخير مستحيل عبر الإنترنت. البث هنا WebRTC
> مباشر (P2P) بأقل تأخير ممكن، وبيظهر لك التأخير الحقيقي في شريط الإحصائيات.
> التأخير بيعتمد أساساً على **سرعة الرفع عند المضيف** وعلى المسافة بين الجهازين.

## جرّب التلات أوضاع

نفس نظام الغرف في التلاتة: كود 6 أرقام، وPeer ID بيبدأ بـ `myeverything-`،
ونفس سيرفر الإشارة (PeerJS public cloud) ونفس بروتوكول التحكم
(إحداثيات نسبية 0..1 + أحداث ماوس/كيبورد). عشان كده الأوضاع متوافقة مع بعض.

### (أ) ديسكتوب — ديسكتوب (الأفضل للعب)
- المضيف: ويندوز — نزّل `MyEverything-Setup-v1.0.0.exe` من Artifacts في
  GitHub Actions، سطّب وافتح.
- الضيف: ماك — نزّل الـ `.dmg` واسحب للـ Applications (أول مرة Right Click ثم Open).
- المضيف يدوس **استضيف غرفة** ويبعت الكود، والضيف يدوس **انضم لغرفة**.
- **التحكم كامل:** الضيف يتحكم بالماوس والكيبورد في متصفح المضيف
  (المضيف يقدر يقفله في أي وقت). صوت اللعبة + شات صوتي.

### (ب) ويب — ويب (الأسرع للتجربة، من غير تسطيب)
- افتحوا الاتنين نفس رابط موقع MyEverything (GitHub Pages — شوف النشر تحت).
- المضيف يدوس **استضيف غرفة — شارك الشاشة**، ويختار **تبويب AirConsole**
  من نافذة المشاركة، ويعلّم على **Share tab audio** عشان صوت اللعبة يوصل.
- الضيف يدوس **انضم لغرفة** ويكتب الكود.
- حدود الويب بصراحة: لازم Chrome أو Edge، ولازم تبويب المشاركة يفضل
  مفتوح (لو المضيف قفل التبويب أو بدّل الشاشة، البث بيقف)، **والتحكم
  عن بعد مش متاح لما المضيف ويب** — المتصفح بيمنع أي صفحة تحقن
  ماوس/كيبورد في تبويب تاني. المشاهدة والشات الصوتي شغالين عادي.

### (ج) ديسكتوب — ويب (مختلط، وده الأنسب ليكم في الغالب)
- **المضيف ديسكتوب (ويندوز) + الضيف ويب (ماك):** شغال كامل — الضيف
  يفتح الموقع بس من غير تسطيب، ويشوف البث ويتحكم (الديسكتوب هو اللي
  بينفذ التحكم).
- **المضيف ويب + الضيف ديسكتوب:** شغال مشاهدة + صوت بس، والتحكم
  مش هيتنفذ لنفس سبب حدود المتصفح اللي فوق.
- نصيحة عملية: خلّوا **المضيف دايماً ديسكتوب** لو عايزين تحكم كامل،
  والضيف يستخدم اللي يريحه (ديسكتوب أو ويب).

في التلات أوضاع، خطوة الدراعات واحدة: كل واحد يفتح `airconsole.com`
على موبايله ويدخل **كود التلفزيون** اللي ظاهر على شاشة اللعبة.

## نشر نسخة الويب على GitHub Pages (من غير سيرفر)

نسخة الويب ملفات static بس (`web/index.html` + `web/app.js` + `web/styles.css`
+ `web/vendor/peerjs.min.js` — مكتبة PeerJS متنسخة محلياً، مفيش اعتماد على CDN).
نفس الريبو بتاع المشروع:

1. ارفع المشروع على GitHub (مثلاً ريبو `MyEverything` عند `MeD-74`).
2. من الريبو: Settings ← Pages ← Build and deployment ← Source: **Deploy from a branch**.
3. اختار Branch: `main`، والمجلد: **`/web`** (مش الجذر — الجذر فيه كود الديسكتوب).
4. دوس Save. بعد دقيقة أو اتنين الموقع يبقى لايف على:
   `https://med-74.github.io/MyEverything/`
   (لو اسم الريبو مختلف، غيّر آخر جزء في الرابط لنفس اسم الريبو).
5. جرّب الرابط من Chrome على جهازين مختلفين: مضيف وضيف بالكود.

ملحوظة: GitHub Pages بيخدم الموقع على HTTPS، وده مطلوب عشان
`getDisplayMedia` ومشاركة الشاشة تشتغل. لو فتحت الملفات مباشرة من
القرص (`file://`) مشاركة الشاشة مش هتشتغل — لازم HTTPS أو `localhost`.

## التسطيب (ديسكتوب)

### ويندوز (المضيف — أحمد)
1. نزّل `MyEverything-Setup-v1.0.0.exe` من قسم Artifacts في GitHub Actions
   (أو من الـ Release لو اتعمل).
2. شغّله Next ثم Install ثم Finish. البرنامج مش موقّع بكود ساينينج،
   فممكن Windows SmartScreen يطلع تحذير أول مرة — دوس More info ثم Run anyway.
3. افتح MyEverything.

### ماك (الضيفة — لولي)
1. نزّلي `MyEverything-v1.0.0-arm64.dmg` (لأجهزة Apple Silicon) أو `x64`
   (لأجهزة Intel القديمة).
2. افتحي الـ DMG واسحبي MyEverything لمجلد Applications.
3. البرنامج مش موقّع من Apple، فأول مرة: Right Click على الأيقونة ثم Open
   ثم Open، بدل الدبل كليك العادي (Gatekeeper).

## طريقة اللعب

1. **المضيف (ويندوز):** دوس **استضيف غرفة** — هيطلع كود 6 أرقام. ابعته للولي.
   AirConsole مفتوح أصلاً جوه البرنامج؛ اختار لعبة.
2. **الضيف (ماك):** دوس **انضم لغرفة** واكتب الكود — هتشوف نفس شاشة المضيف
   لحظياً، وتقدر تدوس وتتحرك بالماوس والكيبورد (لو المضيف سمح بالتحكم).
3. **الدراعات (الموبايلات):** كل واحد يفتح `airconsole.com` على موبايله
   ويدخل **كود التلفزيون** اللي ظاهر على شاشة اللعبة — الموبايل يبقى الدراع.
   دي خطوة AirConsole نفسها، مش من البرنامج.
4. للعب بملء الشاشة دوس **ملء الشاشة للعبة** (وترجع بـ Esc).

## الجودة والتأخير

| الوضع | الاستخدام | احتياج الرفع عند المضيف |
|---|---|---|
| سباق — 720p / 60fps (الافتراضي) | ألعاب سرعة زي سباق العربيات | رفع ثابت 5 ميجا أو أكتر |
| جودة عالية — 1080p / 30fps | ألعاب هادية وصورة أوضح | رفع ثابت 8 ميجا أو أكتر |
| نت ضعيف — 480p / 30fps | النت بيقطع أو الرفع ضعيف | رفع 2–3 ميجا |

- شريط الإحصائيات بيحدّث كل ثانيتين: التأخير (RTT) والسرعة والفريمات.
  دي أرقام حقيقية من WebRTC، مش أرقام وهمية.
- لو التأخير فوق 250ms هيطلع تحذير: جرّب جودة أقل (480p).
- ألعاب السباق هي أصعب حالة للبث الحي؛ لو النت عند المضيف ضعيف،
  حتى أحسن برنامج مش هيقدر يلغي التقطيع — الحل الوحيد جودة أقل أو نت أسرع.

## التقنية باختصار

- ديسكتوب: Electron 45 (Chromium حديث — بيدعم كل ألعاب AirConsole) + PeerJS 1.5.
- ويب: ملفات static + PeerJS 1.5 (منسوخة في `web/vendor/peerjs.min.js`) + `getDisplayMedia`.
- الإشارة (signalling) عن طريق سحابة PeerJS العامة المجانية فقط.
  البث نفسه P2P عبر WebRTC مع Google STUN. مفيش سيرفر وسيط للفيديو
  ومفيش TURN — لو الطرفين ورا NAT صارم، الاتصال المباشر ممكن يفشل
  وساعتها الحل سيرفر TURN (مش متوفر مجاناً هنا).
- التحكم عن بعد: إحداثيات نسبية (0..1) من فيديو الضيف بتتحول لإحداثيات
  المتصفح عند المضيف عبر `sendInputEvent` — وده متاح في الديسكتوب بس.
  نسخة الويب كمضيف بتستقبل أحداث التحكم لكن المتصفح بيمنع تنفيذها.

## البناء من السورس

```bash
npm install
npm start          # تشغيل للتطوير (على لينكس: --no-sandbox مدمج في السكربت)
npm run dist:win   # لازم يتنفذ على ويندوز (GitHub Actions)
npm run dist:mac   # لازم يتنفذ على ماك (GitHub Actions)
```

متبنيش نسخة ويندوز NSIS على لينكس — مفيش wine في البيئة دي، والطريق
الصح هو GitHub Actions (ملف `.github/workflows/build.yml`).

## حل المشاكل

- **الصورة بتقطع:** غيّر الجودة لـ 480p، واقفل أي تحميل/فيديو تاني على نت المضيف.
- **الضيف مش شايف حاجة:** اتأكد إن الكود صح وإن المضيف فاتح البرنامج
  والغرفة لسه مفتوحة؛ جرّبوا تاني بكود جديد.
- **مفيش صوت لعبة:** صوت النظام (loopback) بيتاخد من ويندوز لما يكون متاح؛
  لو مش شغال، صوت اللعبة هيتسمع عند المضيف بس، والشات الصوتي بالمايك شغال عادي.
- **ماك بيمنع الفتح:** Right Click ثم Open (Gatekeeper — البرنامج غير موقّع).
- **البرنامج مش بيفتح على لينكس:** شغّله بـ `ELECTRON_DISABLE_SANDBOX=1 npm start`.
- **نسخة الويب: "مشاركة الشاشة مش شغالة":** لازم HTTPS (GitHub Pages) أو
  `localhost`، ولازم Chrome/Edge. فتح الملف مباشرة `file://` مش هينفع.
- **نسخة الويب: الضيف بيبعت تحكم ومفيش حاجة بتحصل:** ده متوقع — التحكم
  مش متاح لما المضيف ويب. خلّي المضيف نسخة الديسكتوب لو عايز تحكم كامل.
